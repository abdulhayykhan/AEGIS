## 1. Objective and Scope

The baseline strategy is designed to provide an unambiguous, deterministic mathematical logic for testing the entire AEGIS infrastructure: data ingestion, signals library, backtesting harness, risk gate, connector MCP tools, and agent reasoning.

The primary goal of the baseline is **not speculative alpha**, but demonstrating a resilient, verifiable, and testable end-to-end system that strictly honors risk boundaries and abstains when criteria are not met.

## 2. Mathematical Definition & Indicator Logic

All indicators and sizing calculations must be executed by pure Python functions within `src/signals/`, completely independent of the LLM.

### 2.1 Indicators
For any eligible instrument $i$ on daily bars ($1\text{d}$):
1. **Simple Moving Average (50-period)**:
   $$\text{SMA}_{50}(t) = \frac{1}{50}\sum_{k=0}^{49} \text{Close}(t-k)$$
2. **Simple Moving Average (200-period)**:
   $$\text{SMA}_{200}(t) = \frac{1}{200}\sum_{k=0}^{199} \text{Close}(t-k)$$
3. **Average True Range (14-period)**:
   Used for dynamic stop-loss placement:
   $$\text{TR}(t) = \max\Big(\text{High}(t) - \text{Low}(t),\, |\text{High}(t) - \text{Close}(t-1)|,\, |\text{Low}(t) - \text{Close}(t-1)|\Big)$$
   $$\text{ATR}_{14}(t) = \frac{1}{14}\sum_{k=0}^{13} \text{TR}(t-k)$$

## 3. Signal Generation Rules

### 3.1 Long Entry Signal (`BUY`)
A `BUY` signal is generated if and only if all of the following conditions hold:
1. **Trend Filter**: $\text{Close}(t) > \text{SMA}_{50}(t)$
2. **Golden Regime**: $\text{SMA}_{50}(t) > \text{SMA}_{200}(t)$
3. **No Existing Position**: Currently holding 0 units of instrument $i$.
4. **Data Freshness**: Current timestamp is within 2 bar durations of bar $t$.

### 3.2 Long Exit Signal (`SELL` / Close)
An existing long position is signaled for closure if:
- $\text{Close}(t) < \text{SMA}_{50}(t)$ (Trend breakdown), OR
- $\text{SMA}_{50}(t) < \text{SMA}_{200}(t)$ (Regime death-cross), OR
- Dynamic Stop-Loss is hit: $\text{Low}(t) \le \text{Entry Price} - 2 \times \text{ATR}_{14}(\text{entry})$.

### 3.3 Abstention Rule ("No Trade")
- If neither entry nor exit conditions are strictly satisfied, the signal must explicitly evaluate to `NEUTRAL` (`NO_TRADE`).
- The system treats abstention as an optimal, value-preserving action when evidence is ambiguous or absent (Book Ch. 6.5).

## 4. Position Sizing & Order Structuring

The sizing algorithm operates deterministically in `src/signals/sizing.py`:

1. **Calculate Risk Budget**:
   $$\text{Risk Budget} = \text{Account Equity} \times 0.01 \quad (1\%)$$
2. **Calculate Stop Distance**:
   $$\text{Stop Distance} = 2 \times \text{ATR}_{14}$$
   $$\text{Stop-Loss Price} = \text{Entry Price} - \text{Stop Distance}$$
3. **Raw Position Size**:
   $$\text{Raw Units} = \frac{\text{Risk Budget}}{\text{Stop Distance}}$$
4. **Position Cap (10% Equity Constraint)**:
   $$\text{Max Capital Allocated} = \text{Account Equity} \times 0.10$$
   $$\text{Max Units Cap} = \frac{\text{Max Capital Allocated}}{\text{Entry Price}}$$
   $$\text{Final Units} = \min(\text{Raw Units},\, \text{Max Units Cap})$$
5. **Tick & Lot Normalization**:
   - `Final Units` is rounded down to the instrument's `min_size` / step size from the `instruments` table.

## 5. Proposal Structure & Rationale Verification

Every proposal generated by the strategy skill must be fully deterministic and referenceable:
- `instrument`: Symbol (e.g. `BTC/USDT`)
- `side`: `BUY` | `SELL`
- `entry_price`: Verified mark/limit price
- `stop_loss`: Exact calculated price based on $2\times\text{ATR}$
- `take_profit`: Defined target (e.g. $4\times\text{ATR}$ for $2:1$ Reward-to-Risk ratio)
- `size`: Units formatted to tick precision
- `evidence_refs`: Array of database primary keys: `[bar_ids, signal_id]`
- `rationale`: Concise description explaining the SMA crossover and ATR stop distance.
